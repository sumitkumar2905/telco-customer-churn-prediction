# Telco Customer Churn Prediction

## 📌 Project Overview

This project focuses on predicting customer churn using supervised
machine learning techniques.

The project includes data cleaning, exploratory data analysis,
feature engineering, preprocessing, model training, and evaluation.

## 🎯 Objective

To build a machine learning model that can identify customers
who are likely to churn based on their demographic, service,
contract, and billing information.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

9. Model Training
10. Model Evaluation
11. Feature Importance
12. Business Insights

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- Bagging Classifier

## 📊 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 📈 Key Analysis

The project investigates the relationship between customer churn
and variables such as:

- Tenure
- Monthly Charges
- Contract Type
- Internet Service
- Payment Method
- Technical Support
- Online Security
